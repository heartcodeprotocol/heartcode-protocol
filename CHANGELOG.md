# Changelog

All material changes to Heartcode Protocol will be documented here.

## [0.1] — 2026-07-27

### Added

- First public draft of the eight Heartcode principles.
- Preliminary Pass, Concern, Fail, and Insufficient Context rating scale.
- Whole-response evaluation requirements.
- Test-case template.
- Contribution guidelines.
- Explicit non-claims concerning consciousness, universal safety, and authority.

### Status

Experimental public draft released for criticism, testing, and empirical refinement.
